# Gerenciador de Tarefas em Python

Aplicação de terminal desenvolvida para gerenciamento de tarefas diárias.

## Funcionalidades
- Adicionar novas tarefas
- Listar tarefas cadastradas
- Atualizar tarefas existentes
- Marcar tarefas como concluídas
- Deletar tarefas concluídas

## Tecnologias Utilizadas
- Python 3

## Como Executar
1. Certifique-se de ter o Python instalado.
2. Clone este repositório ou baixe o arquivo `gerenciador.py`.
3. Abra o terminal na pasta do arquivo e execute:
   ```bash
   python gerenciador.py
   ```
